# 隐藏内容

这里保存暂时不公开的历史文章及其图片，方便在本地直接浏览和整理。

- `文章/`：48 篇历史 Markdown，按原分类分目录保存。
- `图片/images/`：历史文章的原图和 WebP 封面，保持原来的 `images/...` 相对结构。

这个目录不属于 Astro 内容集合，也不位于 `public/`，因此文件不会复制到网站的 `dist/` 部署产物。仓库仍然是公开的，所以这些文件会保留在 GitHub 和 Git 历史中；这里的“隐藏”仅表示不作为网站内容发布，不表示私密存储。

需要恢复某篇文章时，请让 Codex 将 Markdown 移到 `src/content/blog/<分类>/`，把该文引用的图片移回 `public/images/`，确认 `draft: false`，再执行检查、构建和发布。不要只移动 Markdown，否则图片路径会失效。
